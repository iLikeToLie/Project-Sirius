Maintenance rule:
Add one entry for every released workbook or web version. Record the version,
file or deployment, release date, primary function, key changes, and limitations.

Version 4
File: Friis_RF_Link_and_Interference_Calculator_v4.xlsx
Date: 2026-07-30

Function:
Added native Excel 1D antenna-pattern and off-axis directional-gain modelling.

Key changes:
- Added Antenna Setup with Manual gain, Manual off-axis, and Geometry-derived
  gain-source modes for Tx and Rx.
- Added local-coordinate geometry for path bearing, elevation, and off-axis angles.
- Added editable Tx/Rx horizontal and vertical 1D pattern tables.
- Added linear pattern interpolation in dB without extrapolation.
- Added Horizontal only, Vertical only, and explicit H + V approximation modes.
- Added Pattern View with selectable antenna/plane and a pattern-cut chart.
- Integrated active directional gains into Calculator and Distance Plot.
- Updated Gain Plot so the swept value replaces one active directional gain while
  the other remains fixed.
- Added optional active-pattern gains to Placement Comparison.
- Expanded instructions, warnings, conventions, and limitations.
- Preserved Version 3 results when both antennas remain in Manual gain mode.

Important limitation:
The included antenna patterns are illustrative placeholders. Replace them with
manufacturer or measured data before using pattern-derived results for engineering
decisions. The model uses 1D cuts, not a full 2D or 3D radiation pattern.

Web Version 1.4.0 (based on workbook Version 3)
Deployment: https://iliketolie.github.io/friis-rf-calculator/
Date: 2026-10-26

Function:
Added the Link workspace: direct Tx/Rx placement with optional synthetic terrain.

Key changes:
- New Link workspace view with a plan-view canvas and inspector. Drag Tx and Rx,
  nudge with arrow keys (Shift for 10 m), or type X, Y and height above ground.
- The calculator distance is now the 3D separation derived from antenna
  positions. Typing a separation (canvas or Calculator) moves Tx along its
  bearing with Rx and both heights fixed.
- Optional synthetic terrain (model synthetic-v1) with elevation offset, relief
  scale and contour interval. Antenna elevation = ground elevation + height above
  ground.
- Sensitivity, required receive level and interference threshold boundaries:
  analytic circles on flat ground, terrain-following isolines over terrain,
  evaluated in a web worker.
- Logarithmic 1 MHz to 100 GHz frequency control and status-coloured signal
  animation (paused for reduced motion).
- Scenario schema version 2. Earlier saves and imports migrate to flat ground
  with their original distance.

Calculation scope:
The Version 3 Friis engine is unchanged. Terrain affects only antenna elevations
and the 3D separation fed to it; the result remains a free-space estimate with no
ridge obstruction, diffraction or Fresnel clearance modelling.

Web Version 1.5.0 (based on workbook Version 3)
Deployment: https://iliketolie.github.io/friis-rf-calculator/
Date: 2026-10-26

Function:
Replaced the plan-view Link workspace with a map of Singapore holding up to six
transmitter/receiver sensors.

Key changes:
- Full-bleed OneMap Grey map with hillshading; floating sensor list, selected-
  sensor card and Link settings card (desktop layout).
- Up to six sensors, each switchable between transmitter and receiver. Drag,
  arrow-key nudge (Shift for 10 m) or typed latitude/longitude.
- Each receiver has an intended transmitter (nearest by default) judged for
  desired communication; every other transmitter it receives is judged for
  interference. Intended links and above-threshold interference are drawn.
- Free-space range zones (acceptable, weak, interference) for the selected
  transmitter, using its linked receiver's settings, computed in a web worker.
- Ground elevation from Terrain Tiles on AWS (Terrarium); sea areas count as
  0 m and missing tiles are flagged rather than read as zero.
- The Calculator, sweeps and placement table follow the active link (selected
  receiver and its intended transmitter).
- Scenario schema version 3. Web 1.4.0 and earlier scenarios open as two
  sensors with terrain elevation off, so their results are unchanged.

Calculation scope:
The Version 3 Friis engine is unchanged. All sensors share one operating
frequency. Results remain free-space estimates: terrain does not block the
signal and there is no diffraction or Fresnel clearance modelling. The map
requires an internet connection; map data (c) OneMap Singapore ODL v1.0.

Web Version 1.6.0 (based on workbook Version 3)
Deployment: https://iliketolie.github.io/friis-rf-calculator/
Date: 2026-10-26

Function:
Made terrain drive the link in the Singapore Link workspace.

Key changes:
- Terrain diffraction (ITU-R P.526 Bullington knife edge, 4/3 effective Earth
  radius) over ALOS AW3D30 v4 ground, added to Other loss so the Friis engine
  is unchanged. Each link reports a clearance class (LOS, Fresnel, obstructed).
- Radial coverage map with terrain shadowing, unknown ground hatched, and
  dashed free-space reference rings; Model select (Terrain diffraction / Free
  space).
- Workspace default objective (Desired / Avoidance) with a per-receiver
  override; an avoidance receiver has no intended link.
- Frequency-scaled transmit animation restored on intended links.
- Compact cards: collapsible sensor list, tabbed selected-sensor card, Link
  settings popover, panels fade while dragging, Hide panels toggle.
- Link-budget drawer: every Calculator input and result, the Rx meter and a
  path-profile chart for the active link.
- Scenario schema version 4. 1.5.0 scenarios open with the free-space model,
  so their results are unchanged.

Calculation scope:
The Version 3 Friis engine is unchanged. One Bullington equivalent edge per
path; no building heights, clutter, foliage, rain or multipath. AW3D30 is a
surface model with about 16 % cloud-filled cells. Elevation tiles are generated
locally with `pnpm dem:build` (public/dem is not committed pending JAXA
redistribution terms); missing tiles flag the link as unknown. Elevation
(c) JAXA, ALOS World 3D-30m (AW3D30); map (c) OneMap Singapore ODL v1.0.
