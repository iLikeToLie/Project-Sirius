# Track B performance measurements

Baseline captured on `feature/antenna-templates-perf` after Track A and before source edits. Both builds used `corepack pnpm build --configLoader runner` because the default Vite config loader hit a sandbox directory-read denial. Browser runs used headless Chromium with SwiftShader and a dedicated Vite preview on port 5200. Port 5199 was already serving a different build.

## Twelve sensors

The unmodified `twelve-sensors.mjs` passed at 1,440 and 390 px in both runs. The script has no built-in drag or rename measurements, so the same temporary in-memory extension ran against both builds at 1,440 px. It selected T1, fit the map, dragged T1 by 60 × 20 px over 20 mouse moves, verified that its saved longitude changed, then renamed it and waited for the new label.

Worker counts include all browser `Worker.postMessage` calls through coverage settling plus 250 ms after each action. The action times cover the Playwright input and, for rename, the label assertion. They exclude the separate settle and saved-position checks. These are single runs, and the worker counts include MapLibre traffic.

## Track B checks

- B1 ran because the default Calculator tab draws no chart. Chart.js now loads on the first sweep visit.
- B2 ran. The presets and polar plot had no eager production importers outside the Antennas tab.
- B3 ran. Unit tests cover debounce and flush. A browser reload started 15 ms after the edit action began, while storage still held the old value. The edited value survived. A separate hidden-visibility event flushed another pending edit.
- B4 ran. Stationary pairs reuse settled results within the same ground sampler version. Aim-tracked endpoints and pairs whose automatic desired status flips are refreshed.
- B5 ran. Elevation's `settle` only batched the status change. Elevation and building versions had bumped per successful tile and now publish at most once per frame per hook.
- B6 ran. Map rotation handlers now coalesce by animation frame. Sweep point calculations depend on numerical link inputs and sweep settings.
- No Track B items were skipped.

All 475 scoped Vitest tests passed. TypeScript and the production build passed. The `twelve-sensors`, `drive-map`, `directional-antennas` and `link-budget-drawer` browser scripts all exited successfully.

Channel rejection, noise floor and polarization browser checks also passed. The building-tile recovery scenario passed for both transient and persistent failures with OneMap served from an in-memory fixture. The unmodified recovery script hit the sandbox's external network restriction.
